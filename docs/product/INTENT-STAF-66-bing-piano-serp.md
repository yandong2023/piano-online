## 1. 为什么先核意图

Atlas 的提案与建议都写明了先决条件：Bing「钢琴」是本轮曝光量最大的词（227 clicks / 17,046 impr / 占查询词行曝光 65.5% / CTR 1.33% / 位置 9–10），但**先要看清这个词排在前面的结果是什么类型**，再决定要不要为它建页。若排在前面的都是在线钢琴工具站，说明意图与本站首页同质，建新页只是和自己抢；若是商城/曲谱/百科/视频，则存在内容形态缺口，建页有理。

## 2. 方法与限制（先说清楚可信边界）

- 手段：直接抓取 Bing 网页搜索结果页，**国内版**，`setlang=zh-hans&cc=cn`，未登录，2026-10-22 约 15:45 UTC。
- 取数：`#b_results > li.b_algo` 前 10 条自然结果的目标域 + 标题/摘要关键词。
- 查询词：`钢琴`（主核）、`钢琴模拟器`（对照，验证是否同一意图）。
- **限制（不可忽略）**：
  1. 网页 UI 的排序 ≠ Bing Webmaster `GetQueryStats` 的平均位置样本（后者是跨时间窗平均，且站点属性是 `www.pianoonline.cc`）。本次站点未出现在 UI 前 10，**不能据此说排名掉了**。
  2. 单次抓取、无位置模拟、无法排除个性化；结论只用于判断「结果类型构成」，不用于判断具体名次。
  3. 只看自然结果，未含广告/商品卡/视频卡。

## 4. 结论与推断

### 4.1 结论（基于实测，置信度高）

「钢琴」在 Bing 国内版是**工具型意图**：用户要的是「打开就能弹的在线钢琴」。排在前面的全是虚拟钢琴/在线钢琴产品页，没有商城、曲谱、视频、教程内容。**不存在内容形态缺口**——本站首页（`/`，`body.studio-page`，就是在线钢琴本体）已经是这个意图的正确答案，且已在位置 9–10。

### 4.2 推断（置信度中，附反证方式）

差距更可能来自**域名/页面权重与标题同义词覆盖**，而不是「缺一个页面」：
- 第 1 名标题把 `自由钢琴 / 在线钢琴 / 键盘钢琴 / 模拟钢琴` 四个词堆在一句里；第 2、9 名同理。本站首页 title 已是「在线钢琴模拟器 · 跟着提示学歌」，词面偏窄。
- **反证方式**：若新建独立页后 6 周内进入 Bing 前 5 且首页位置不下降，则本推断错。

### 4.3 建独立页的具体代价（若选 A）

| 项 | 内容 |
|---|---|
| 新 URL | 1 个（`/piano-cn/` 之类），需进 sitemap（当前 357 条会变） |
| 内容 | 与首页高度重复（同为在线钢琴），有**关键词自我蚕食**风险：两个 URL 争同一查询，Bing 可能择其一或都降权 |
| 内链 | 需与首页互链并明确 canonical 关系，改动面比提案 1 大一个量级 |
| 观察成本 | 提案给的验证窗口 6 周，跨过 11-06 复盘 |
| 归因 | 与 STAF-64 未结的归因窗口叠加（见 `NOTE-STAF-66-attribution-window.md`） |

### 4.4 若用户仍要做，PRD 需要补的前置（本单不写）

需要先定：目标 URL 与 canonical 策略（首页是否让位）、与首页的内容差异点（不能只是同义词重排）、sitemap 数量口径变更、以及「首页位置不得下降」的监测线。这三项属于**范围与对外承诺**，产品不自行拍板。

## 5. 决策单（交 Morgan 转用户）

```
[需决策] Bing「钢琴」大词：是否为它单独建落地页

背景：Atlas 提案 2（STAF-66）要求先核 Bing SERP 意图再定是否建页。产品已实测（2026-10-22）：
「钢琴」Bing 国内版前 10 条自然结果 = 9 个在线钢琴工具站 + 1 条百度百科，0 商城 / 0 曲谱 / 0 视频 / 0 教程；
对照词「钢琴模拟器」前 10 域完全相同。即该词意图与本站首页同质，不存在内容形态缺口。
站点该词现状：227 clicks / 17,046 曝光 / CTR 1.33% / 位置 9–10（Bing GetQueryStats 90 天，Atlas 实测）。

选项 A：建独立「钢琴」落地页
  做法：新增 1 个 URL，承接泛「钢琴」意图，进 sitemap，与首页互链并定 canonical 让位关系。
  代价：新页面+内容+内链，约 3–5 人日；观察期 6 周。
  风险：与首页争同一意图（关键词蚕食），可能出现两页都掉；且需改 sitemap 口径（357 条这一基线会被打破，影响其他在跑的 SEO 验收）。

选项 B：不建页，改为观察 + 11-06 复盘后按数据再判（产品建议）
  做法：本轮不动首页 title（Atlas 已明确「不要继续堆词」），把「钢琴」列入 11-06 复盘的观察项；
        同时把「CTR 是否随排名自然改善」与「同义词覆盖」作为复盘问题记录。
  代价：继续以 1.33% CTR 接收 17,046 曝光，短期不改善。
  风险：若 11-06 数据显示该词曝光继续放大而 CTR 不动，等于又推迟一轮。

选项 C：不建新页，改由现有首页承接，只做「非 title」的差异化（如首页首屏文案/结构化数据补同义词）
  做法：不动 title，只在首屏 H1 区/FAQ/结构化数据补「自由钢琴、键盘钢琴」等同义词，观测 CTR。
  代价：1 人日内，可与提案 1 同批。
  风险：属于「继续往首页堆词」的变体，与 Atlas 的明确建议相抵；效果依赖 Bing 重抓与重排，14 天内不可测。

建议：B。理由：意图已核对为工具型，本站首页就是答案页，问题在权重与词面覆盖而非缺页面；
在 11-06 归因结论出来前，任何新页都无法归因，且会打破 sitemap 357 条这一正在被验收的基线。

不决策的后果：提案 2 无法进入开发排期（本单只交付提案 1 的 PRD）；同时 11-06 复盘会缺一条
「该词是否值得投入」的判断依据，下一轮还可能重新讨论同一个问题。
```
