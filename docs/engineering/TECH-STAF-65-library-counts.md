# STAF-65 曲库分类计数与月光教程补修

对应需求：STAF-65 issue 初始版（2026-10-22），覆盖 AC1–AC7；基线为最新 origin/main `a7704dc`，包含 `b38cb10`。在独立 worktree / `fix/staf-65-library-counts` 分支开发。

## 方案

选择：在 `library-browser.js` 既有 `update()` 内，卡片筛选完成后逐分类计算可见卡片数，同时更新标题计数与分类显隐；生成器只纠正 moonlight 教程映射。SSR 的完整分类计数保持原样。中文分类计数为 `N 首`，英文与总数相同为 `N songs`。

备选：在构建时按难度预生成分类计数并让客户端切换。未选择，因为搜索词与分类组合仍需客户端计算，会产生两套口径；直接对已筛选卡片计数更小且准确。

## 影响面

- 上游：SSR 曲库 HTML、搜索输入、难度下拉框/hash、分类按钮、清除筛选。
- 下游：可见分类标题计数、空态及曲库总数；月光奏鸣曲中英文相关教程。
- 接口/数据结构/迁移/权限/多租户/异步任务：无变更；无新 URL、无网络查询、无数据迁移。
- 缓存/第三方：沿用现有资源 URL 与 Vercel 部署方式，生产抓取脚本并在浏览器复验；不改 `vercel.json`。新会话加载新部署，已打开页面需刷新。
- 繁体教程仍由生成器既有逻辑跳过，不新增空容器。

## 变更清单

- `js/library-browser.js`：分类显隐与计数共用当前可见卡片数量。
- `scripts/render-song-pages.mjs`：moonlight → `classic-piano-pieces-for-beginners`。
- `tests/song-library.test.mjs`：筛选组合的分类计数、中英文文案及月光三语言链接回归。
- 生成 HTML：只提交构建流程实际跟踪的月光中英文页面变化。
- 本 TECH 与自测附件：验收方法、证据和发布/回滚记录。

## 上线与回滚

1. 本地验收并创建 base main PR，描述逐条给出 AC 证据。
2. 依据 issue 明确授权合并发布；检查目标 Vercel 项目、生产域名及提交，等待本次部署结果。
3. 生产复验后在 issue 附本 TECH、自测及发布证据，置 in_review 并交质检（本单明确指定）。
4. 回滚：在独立分支对 PR 的最终 squash 提交执行 `git revert <merge-sha>`，经 PR 合回 main 后部署。仅静态代码/内容变化，无持久数据，完全可逆。
